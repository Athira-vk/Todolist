
# To-Do List App

This project is a simple and interactive To-Do List Application built using HTML, CSS, and JavaScript. The goal is to help users manage their daily tasks efficiently by allowing them to add, edit, and delete tasks in a user-friendly interface.




## Features

-  Users can enter new tasks and click the "Add" button to add them to the list.
- Each task has a checkbox to mark it as completed or incomplete.
-  Users can edit the description of any task by clicking on it.
- Tasks can be removed from the list when no longer needed.
- Basic validation prevents users from adding empty tasks and ensures a smooth experience.
-  The app stores the to-do list data in the browser's local storage so tasks persist even after refreshing the page.
- The application adapts to different screen sizes, ensuring it works well on both desktop and mobile devices.

## System Modules

### 1. **Task Management**
   - **Add Task**: Users can input a new task into a text input field and click the "Add" button to add it to the list.
   - **Edit Task**: Each task can be edited by clicking on the task description.
   - **Delete Task**: Users can delete tasks that they no longer need.
   - **Mark as Completed**: Tasks can be marked as completed by checking the checkbox next to each task.

### 2. **Local Storage Integration**
   - **Persistence**: All tasks are stored in the browser's local storage, ensuring that tasks persist even after a page refresh.
   - **Retrieval**: When the app is loaded, it retrieves the list of tasks from the local storage and displays them.

### 3. **User Interface (UI)**
   - **Input Section**: A text field and "Add" button are provided for task entry.
   - **Task List Display**: Tasks are displayed in a list with checkboxes for completion, edit, and delete options.
   - **Responsiveness**: The UI adapts to different screen sizes using CSS media queries.

### 4. **Validation**
   - **Empty Task Prevention**: Users cannot add empty tasks, ensuring only valid data is entered.





## Tech Stack

- **HTML**: Structure of the app.
- **CSS**: Styling and responsive design.
- **JavaScript**: Functionality for adding, editing, and deleting tasks.
- **Local Storage**: Persist tasks even after page refresh.

##  Installation


To run this project locally, follow these steps:



### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Athira-vk/Todolist.git
```



### 2️⃣ Open the Project

 Open the project folder in your code editor (e.g., Visual Studio Code).

### 3️ Install Live Server (if not installed)

If you don’t have the Live Server extension in VS Code, install it from the Extensions Marketplace.




### 4️⃣  Run the App:

Right-click on index.html and select "Open with Live Server" to run the app in your browser.
